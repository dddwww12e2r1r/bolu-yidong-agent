# 波动率异动预警智能体

仓库前缀：`bolu-yidong-agent`

在线演示：<https://3a92e18687384a4bb5dc4587978299ef.app.workbuddy.link/>

这是一个面向海外用户的加密货币合约市场风险观察工具。输入合约代码后，系统读取小时级 K 线，计算 ATR、7 天年化历史波动率，并将当前市场状态分为平静、正常、活跃、剧烈四档。

项目名称保留“币安作品6”，但不调用 Binance 接口。

## 核心功能

- 近 7 天历史波动率曲线
- 14 小时 ATR，以价格百分比展示
- 当前 7 天波动率与近 30 天基准均值对比
- 当前波动率放大达到 1.8 倍，或年化波动率达到 120% 时触发“波动率爆发”
- 平静、正常、活跃、剧烈四档波动率状态
- 深色风险监控界面
- 输入 `BTCUSDT`、`ETHUSDT`、`SOLUSDT` 等 USDT 永续合约进行分析

## 数据来源

系统按以下顺序读取海外公开行情接口：

1. Hyperliquid Perpetual：优先数据源
2. OKX Swap：备用数据源
3. Bybit Linear：备用数据源
4. 当实时接口都不可用时，显示明确标注的演示数据

项目不需要 API Key，不连接用户交易账户，也不执行自动交易。

## 本地运行

需要 Python 3.10 或更高版本。

在项目根目录运行：

```bash
python agent.py --port 8016
```

然后打开浏览器：

```text
http://127.0.0.1:8016
```

不要直接双击 `static/index.html`。因为 HTML 页面需要通过 `agent.py` 后端访问 `/api/analyze` 数据接口。

## 智能体工作流程

```text
输入合约代码
    ↓
校验 USDT 永续合约格式
    ↓
获取海外公开 K 线
    ↓
计算 ATR 和历史波动率
    ↓
对比近 30 天波动率基准
    ↓
判断波动率等级和是否爆发
    ↓
在网页中展示曲线、指标和风险提示
```

## 技术说明

- 后端：Python 标准库 `http.server`
- 前端：HTML、CSS、JavaScript
- 数据接口：Hyperliquid、OKX、Bybit 公共接口
- 支持 `PORT` 环境变量，适合部署到公网服务
- 使用内存缓存减少重复请求
- 接口异常时进行结构化错误处理，避免页面出现空白或 JSON 解析错误

## 重要说明

本项目仅用于市场观察、风险教育和参赛展示，不构成投资建议、交易建议或收益承诺。历史波动率不能预测未来价格方向，使用者应自行判断风险。
