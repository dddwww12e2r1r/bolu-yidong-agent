# 波动率异动预警智能体 · 气象台

仓库前缀：`bolu-yidong-agent`

在线演示：<https://3a92e18687384a4bb5dc4587978299ef.app.workbuddy.link/>

> 这是一间**波动率观测站**：它不预测价格涨跌方向，只回答一件事——
> 市场的「运动速度」是不是突然变快了。输入一个 USDT 永续合约，
> 它播报一张**预警信号单**：预警等级（平静 ● / 正常 ●● / 活跃 ●●● /
> 剧烈 ●●●●）、观测数据、预警依据、防灾提示。

## 一屏速览

| 项目 | 说明 |
|---|---|
| 观测对象 | USDT 本位永续合约（如 BTCUSDT / ETHUSDT / SOLUSDT） |
| 预警等级 | 平静 ●（年化 <35%）/ 正常 ●●（≥35%）/ 活跃 ●●●（放大 ≥1.3 倍或年化 ≥70%）/ 剧烈 ●●●●（放大 ≥1.8 倍或年化 ≥120%，触发「⚠ 波动率爆发」） |
| 判定引擎 | `sources.py` 的 `calculate`（自研纯函数，网页与命令行共用同一段代码，可逐项复核） |
| 数据通道 | 命令行四条（多平台行情 / 币安合约实时 / 官方 CLI / 官方归档），网页版与默认通道同源 |
| 两种形态 | 网页监控面板 + 命令行智能体（可被技能安装器装载、被其他 Agent 直接调用） |
| 免责 | 仅用于市场观察与风险教育，不构成投资建议 |

## 四条观测通道

| 怎么播 | 数据从哪来 | 口径 | 通道标识 |
|---|---|---|---|
| `python agent.py BTCUSDT` | 多平台公开行情：Hyperliquid → OKX → Bybit 三连（与网页版同源同引擎） | 实时 | `source=realtime via=market-route` |
| `python agent.py BTCUSDT --live` | 币安合约公开接口 1h K 线 1000 根（直连不通自动探测本机代理端口） | 实时 | `source=live via=fapi-route` |
| `python agent.py BTCUSDT --skill` | 币安官方 binance 技能驱动的官方 CLI（`binance-cli request GET`） | 实时 | `source=skill via=binance-cli` |
| `python agent.py BTCUSDT --official` | 币安官方开源数据仓库：1h K 线月度 + 日度归档拼到 ≥720 根 | **T+1**（截至上一归档日收盘） | `source=official via=official-archive` |

自然语言也认：`python agent.py "用官方归档看看 ETHUSDT"`。
命令行取不到数就**如实报错退出，不拿演示数据充数**（网页版保留演示降级并明确标注）。

## 快速开始

需要 Python 3.10+，无需任何第三方依赖与 API Key。

```bash
# 网页监控面板（原功能不变，默认 8002 端口，PORT 环境变量优先）
python agent.py

# 命令行预警信号单
python agent.py BTCUSDT
python agent.py BTCUSDT --official        # 免代理：官方归档 T+1
python agent.py BTCUSDT --json            # 纯 JSON（供程序调用）
```

不要直接双击 `static/index.html`——网页需要通过后端访问 `/api/analyze` 数据接口。

## 技术说明

- 后端：Python 标准库 `http.server`，零第三方依赖
- 前端：HTML + CSS + JavaScript，深色风险监控界面，无构建工具
- 判定口径：对数收益率年化 → 近 7 天 / 近 30 天（去最近 24 小时）基准对比 → 四档划分（公式全部公开在 SKILL.md）
- 支持 `PORT` 环境变量部署公网；接口异常做结构化错误处理
- 引擎与命令行共用：`sources.py` 即改造前网页版主程序的逐字节副本（引擎一行未改）

## 重要说明

本项目仅用于市场观察、风险教育和参赛展示，不构成投资建议、交易建议或收益承诺。
历史波动率不能预测未来价格方向，波动率预警说的是「运动速度」不是方向，
使用者应自行判断风险。
